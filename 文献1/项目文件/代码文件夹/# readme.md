# readme
本项目复现了论文《Feedback-based platoon control for connected autonomous vehicles under different communication network topologies》中的核心算法 。通过分布式反馈控制协议，实现了多台智能网联汽车（CAV）在不同通信拓扑下的纵向与横向协同编队 。
## 背景
### 核心问题：
在智能网联交通环境下，如何让多辆自动驾驶汽车快速、稳定地形成编队，并保持设定的几何构型与速度一致？
### 痛点析构：
解决cavs中跟随者过度依赖虚拟领导者的问题。因而重新设计一种通信网络拓补优化收敛性（达到一致速度）和鲁棒性（应对干扰能力）
### 解决方案：
通过控制输入加速度来控制每个车的速度和位置变化以达到目标状态。其中加速度为：动力加速度（整个车队的目标加速度）减去纠正加速度（关系权重乘速度误差（阻尼力）与位置误差（弹簧力），其中关系权重为：跟随者之间、跟随者与领导者的关系权重（邻接矩阵）（实现通信网络的清晰连接）。最后用物理定论和引论证明可行性。
##  项目介绍
### 功能模块：
针对任务要求，项目采用了模块化面向对象设计：
#### 输入输出模块（main文件）：
负责解析用户参数或加载 config.json，实现逻辑与数据分离。可手动输入也可导入文件，方便输入不同数据模拟情况。
#### 核心动力学模块（dynamics文件）：
基于公式3实现车队各项参数以及加速度的设计。项目为了改变位置和速度，将运动过程切割成无数小块，运用微元法逐帧计算车辆状态，让其逐渐靠近目标状态（一致速度，理想间隔）
#### 自适应稳定状态检测器（adaptive文件）：
实时计算系统误差范数，作为“裁判”控制仿真进程。
#### 可视化模块（visualizer文件）：
处理时序轨迹数据，渲染图表与动图。
#### 自适应时间设计 
针对任务中“自行判断编队完成”的要求，本项目设计了滑动窗口收敛判定算法：
动态结束：实时监控所有车辆的最大位置和速度误差范数。当误差持续低于阈值（如 0.05）达 1 秒时，程序自动提前停止。
自动延时：若在预设时间内未达成编队（如由于通信拓扑稀疏导致收敛慢），系统会自动延长仿真时间，直至达成目标或触碰安全上限。

## 文件说明：
main.py: 系统总调度。集成动力学计算、自适应监控与可视化逻辑。
dynamics.py: 物理引擎。实现论文公式 (3) 的加速度计算与数值积分 。
adaptive_stop.py: 逻辑裁判。负责执行误差范数检测与自适应时间控制。
io_manager.py: 交互中心。处理 JSON 解析与控制台手动输入逻辑。
visualizer.py: 图形渲染。生成轨迹图 (Fig.4)、间距图 (Fig.5)、速度图 (Fig.6) 及 GIF 动画 。config.json: 标准配置。存储论文实验的原始初始状态与增益参数 。
requirement.txt：环境配置要求
## 快速开始
### 第 1 步：启动主程序
在终端中进入你的项目目录，运行以下命令：

```Bash
python main.py
```
### 第 2 步：选择输入模式
程序运行后，终端会打印欢迎界面并提示你选择模式：
#### 模式 1（加载 json 文件）：
输入 1 并回车。
提示输入文件路径时，直接按回车（默认读取 config.json）。
推荐场景：快速复现论文结果、进行标准测试。
#### 模式 2（手动输入）：
输入 2 并回车。
程序会一步步询问你：车辆数量、每辆车的初始 X/Y 坐标、初始速度、期望间距，以及是否连接领航车。
### 查看结果
仿真结束后，系统将自动生成：
位置轨迹图：验证车辆是否形成设定的几何阵型 。
误差收敛图：观察纵向与横向间距如何趋于期望值 。
速度共识图：确认所有跟随车速度是否与领航车达成一致 。
platoon_simulation.gif：直观展示编队全过程。
<mark>注意！每弹出一个窗口都请关掉，最后你会在终端看到gif图努力渲染中，在弹出gif图生成结束保存成功的文字之前不要关掉终端，也不要打开gif图！</mark>
然后就可以Ctrl+C退出，如果想要再进行一次，更随着第一步开始。
