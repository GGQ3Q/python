# 运行操作指南
## 第 1 步：启动主程序
在终端中进入你的项目目录，运行以下命令：

```Bash
python main.py
```
## 第 2 步：选择输入模式
程序运行后，终端会打印欢迎界面并提示你选择模式：
### 模式 1（加载 json 文件）：
输入 1 并回车。
提示输入文件路径时，直接按回车（默认读取 config.json）。
推荐场景：快速复现论文结果、进行标准测试。
### 模式 2（手动输入）：
输入 2 并回车。
程序会一步步询问你：车辆数量、每辆车的初始 X/Y 坐标、初始速度、期望间距，以及是否连接领航车。
推荐场景：你想亲自测试极端初始条件（比如把一辆车放得很远），观察自适应算法如何延长仿真时间。

## 第 3 步：观察自适应仿真过程
终端会实时输出仿真进度。

case1：如果一切顺利，可能会看到 编队已在    秒时自适应完成并稳定，提前结束仿真

case2：如果设置的初始位置离谱，会看到：达到预设最大时间 20.0s，但编队仍未完成，自动延长 10 秒...然后回复case1的回答
